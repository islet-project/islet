pub fn generate_seed(context: &[u8], input_key: &[u8], label: &[u8]) -> Vec<u8>
Expand description

Derives key material from a symmetric key, some label and input data. Key material is a derived 256-bit symmetric key using counter-mode KDF complying with NIST SP800-108, where the PRF is a combined sha256 hash and an ECB-mode AES encryption.

§Arguments

  • input - A binary data
  • input_key - A 256-bit symmetric input derivation key
  • label - Unique label describing seed purpose
